# ۰۹ — مشتق و فیلتر کردن

## چرا مشتق خام استفاده‌نشدنی است

مشتق، نویز فرکانس‌بالا را **تقویت** می‌کند. یک نویز با دامنهٔ ۰.۰۱ و فرکانس
۱۰۰ هرتز، بعد از مشتق‌گیری دامنه‌ای در حد $0.01 \times 2\pi \times 100 \approx 6.3$
پیدا می‌کند. با $K_d = 0.1$ این یعنی ۰.۶۳ واحد نویز روی خروجی — که معمولاً از
کل سیگنال کنترلی بزرگ‌تر است.

به همین دلیل PIDX **همیشه** مشتق فیلترشده دارد:

$$D(s) = \frac{K_d s}{1 + T_f s}$$

## انتخاب $T_f$

```c
PID_SetDerivativeFilterN(&pid, 10.0f);   /* Tf = Td / N */
/* یا مستقیم: */
PID_SetDerivativeFilter(&pid, 0.02f);    /* Tf بر حسب ثانیه */
```

| $N$ | رفتار |
|---|---|
| ۲–۵ | فیلتر قوی، مشتق کُند ولی تمیز |
| **۱۰** | **پیش‌فرض توصیه‌شده** |
| ۲۰+ | فیلتر ضعیف، فقط روی سیگنال تمیز |

اگر $N$ خیلی بزرگ باشد عملاً فیلتری وجود ندارد؛ اگر خیلی کوچک باشد مشتق آنقدر
کُند می‌شود که فایده‌اش را از دست می‌دهد.

## سه حالت مشتق

```c
PID_SetDerivativeMode(&pid, PID_DERIV_ON_MEASUREMENT);   /* پیش‌فرض */
```

| حالت | رفتار |
|---|---|
| `PID_DERIV_ON_MEASUREMENT` | پلهٔ setpoint وارد مشتق نمی‌شود — **پیش‌فرض** |
| `PID_DERIV_ON_ERROR` | کلاسیک؛ derivative kick دارد |
| `PID_DERIV_ON_WEIGHTED_ERROR` | با $\gamma$ وزن‌دهی می‌شود (§۱۰) |

«Derivative kick» یعنی وقتی setpoint پله‌ای عوض می‌شود، مشتق یک ضربهٔ بزرگ
تولید می‌کند که روی محرک واقعاً دیده و شنیده می‌شود.

## فیلتر ورودی (جدا از فیلتر مشتق)

```c
PID_SetInputFilter(&pid, 0.05f);   /* ثابت زمانی LPF روی اندازه‌گیری */
```

این کل سیگنال اندازه‌گیری را فیلتر می‌کند، نه فقط مسیر مشتق. مفید وقتی سنسور
نویزی است، ولی **تأخیر فاز اضافه می‌کند** که حاشیهٔ پایداری را می‌خورد.

قاعده: اول فیلتر مشتق را امتحان کنید. فیلتر ورودی فقط وقتی که نویز آنقدر بد
باشد که جملهٔ تناسبی را هم خراب کند.

## ماژول فیلترهای مستقل

`pid_filter.h` چند فیلتر آماده دارد که مستقل از کنترلر استفاده می‌شوند:

```c
PID_MovingAvg avg;
PID_MovingAvg_Init(&avg, buffer, 8);
float smooth = PID_MovingAvg_Update(&avg, raw);
```

- `PID_MovingAvg` — میانگین متحرک با بافر کاربر (بدون malloc)
- `PID_RateLimiter` — محدودکنندهٔ نرخ تغییر

۸۲ assertion این ماژول را پوشش می‌دهند.

## وقتی $K_d = 0$ بهتر است

روی خیلی از فرایندهای صنعتی (مخصوصاً دما با نویز سنسور)، PI ساده بهتر از PID
جواب می‌دهد. مشتق فقط وقتی ارزش دارد که:

- سیگنال نسبتاً تمیز باشد، **و**
- فرایند تأخیر قابل‌توجهی داشته باشد که مشتق بتواند پیش‌بینی کند.

اگر شک دارید، با $K_d = 0$ شروع کنید.
